## Organic Discovery: How Each Platform Surfaces Content to Non-Followers

The operator's goal is not to broadcast to existing followers. It is to be found by people who have never heard of GPE — people searching for "things to do in Chicago this weekend" or "free events near me."

| Platform | Discovery mechanism for non-followers | Event-specific discovery | Local/geo targeting |
|----------|--------------------------------------|------------------------|-------------------|
| **Facebook Events** | Dedicated event search + recommendation engine. Users search by date, location, category. Events surface in "Events Near You" feed. | ✅ Purpose-built — the only major platform with a native event search system | ✅ Location-based event recommendations |
| **Facebook Groups** | AI-powered Group Discovery uses 34 contextual signals. "Local community news and events" is the fastest-growing category (+68.9% YoY) | ⚠️ Indirect — events shared in groups, not searchable as events | ✅ Neighborhood-level groups |
| **Instagram Explore** | Algorithm surfaces content based on interest, engagement, and location signals | ❌ No event-specific discovery layer | ⚠️ Location tags, but no event search |
| **TikTok For You** | Algorithm surfaces content to non-followers based on engagement patterns | ❌ No event discovery | ⚠️ Limited geo-targeting |
| **X/Twitter** | Search, trending topics, algorithmic timeline | ❌ No event discovery | ❌ Limited local |

**Facebook Events is the only major platform with a dedicated event search and recommendation engine.** When a Facebook Event is created, it enters this system automatically. People searching for local events find it without following the page. This is net-new organic discovery, not follower-dependent reach.

## Key Findings

1. **The goal is organic discovery, not audience migration.** Email subscribers already have the content. Social media's value is reaching people who don't know GPE exists — net-new audience through platform discovery algorithms.

2. **Facebook Events is the only platform with a built-in event discovery engine.** Auto-created events enter Facebook's "Events Near You" recommendation system, surfacing to people searching for local activities without requiring them to follow the page. No other major platform offers this.

3. **Facebook has the highest event-specific impact overall** — it drives ~50% of social-discovered event sign-ups, and "local community news and events" groups are the fastest-growing category (+68.9% YoY).

4. **Instagram provides supplementary visual discovery** for the 18-34 demographic. It shares Meta infrastructure with Facebook, enabling cross-posting with near-zero additional effort. However, it lacks an event-specific discovery layer — reach depends on the Explore algorithm, not event search.

5. **Both Facebook and Instagram can be fully automated from GPE's existing event data** — titles, dates, images, and descriptions map directly to post formats and Facebook Event schema without additional content creation.

6. **TikTok and YouTube require video content** that cannot be auto-generated from existing structured data. High effort, conflicts with the automation goal.

7. **GPE's existing Facebook page (26 followers) has Meta Business Suite and Instagram already connected.** The infrastructure for automated posting and cross-platform publishing is in place. The gap is content.

8. **The event attendance market is growing** — 79% of 18-35 year olds plan to attend more events in 2026, with strong demand for hyperlocal, community-oriented experiences. This is exactly GPE's positioning.
